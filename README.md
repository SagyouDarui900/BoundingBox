# AviUtl2 BoundingBox

AviUtl2のテキストなどの個別オブジェクトに、アルファ情報をもとにしたバウンディングボックス（枠線・背景座布団）を付加するスクリプトです。

## 概要

現在のオブジェクト画像から不透明な範囲（文字など）の外接矩形を検出し、その外枠線（ボーダー）や背景座布団を描画します。

以下の設定に対応しています：

- **しきい値（threshold）**: オブジェクトの不透明ピクセルと判定するアルファの境界値（0〜255）
- **線の太さ（line_width）**: ボックスの枠線の幅を指定（0〜100px、デフォルト: 1px）
- **透明度（opacity）**: ボックスの透明度（0〜255、デフォルト: 255）
- **背景塗りつぶし（fill）**: 有効にすると枠線だけでなくボックス内部全体を指定色と透明度で塗りつぶします（「ボックスのみ」が無効な場合はオブジェクトの不透明部分を保持します）
- **文字を前面にする（text_front）**: 
  - **ON**: 文字を最前面にし、枠線が文字の上に被らないように背後（余白側）へ描画します。
  - **OFF**: 枠線を文字の前面に描画（半透明時はブレンド）します。
- **透明度を2値化（binary）**: 有効にするとボックスの透明度設定を無視し、完全不透明（255）として描画します
- **ボックスのみ（only）**: 元のオブジェクトを消去し、ボックス（枠線および塗りつぶし）のみを表示します
- **色（color）**: ボックスの色を指定

## 導入方法

1. [Releases](../../releases) から最新の `BoundingBox.anm2` と `BoundingBox.mod2` をダウンロードします。
2. ダウンロードした2ファイルを、AviUtl2のスクリプトフォルダ（`script` フォルダ等）へコピーしてください。
3. 導入後、AviUtl2の「キャッシュを破棄」を実行するか、AviUtl2を再起動してください。

## 使い方

1. テキストオブジェクトを作成します。
2. テキストを「個別オブジェクト」として表示します。
3. アニメーション効果から「Bounding Box」を追加します。
4. 目的に応じてパラメータを調整します。

### 主な使い分け

- **文字の外側に枠線だけをつけたい場合（文字が最前面）**:
  - `背景塗りつぶし`: OFF
  - `文字を前面にする`: ON
  - `線の太さ`: 1〜（お好みの太さ）
  - `ボックスのみ`: OFF
- **文字の上に枠線を重ねたい場合（図形が前面）**:
  - `文字を前面にする`: OFF
- **文字の背後に座布団（背景ボックス）を敷きたい場合**:
  - `背景塗りつぶし`: ON
  - `文字を前面にする`: ON
  - `線の太さ`: 0（枠線なし）または 1〜（枠線あり）
  - `ボックスのみ`: OFF
- **文字サイズちょうどの四角形（ボックス）だけが欲しい場合**:
  - `ボックスのみ`: ON
  - `背景塗りつぶし`: ON（全体塗りつぶし）または OFF（枠線のみ）

## ファイル構成

| ファイル / フォルダ | 内容 |
| --- | --- |
| `BoundingBox.anm2` | AviUtl2用アニメーション効果スクリプト |
| `BoundingBox.mod2` | 高速ピクセル処理を行うスクリプトモジュール（64bit DLL） |
| `BoundingBox.cpp` | `BoundingBox.mod2`のC++ソースコード |
| `build-BoundingBox.ps1` | スクリプトモジュールのビルドスクリプト（MSVC / cl.exe） |

## ビルド

Visual Studio Build Tools など（MSVC x64）が利用可能な環境で以下を実行します：

```powershell
.\build-BoundingBox.ps1
```

※`aviutl2_sdk` がローカルに見つからない場合、スクリプトが自動で GitHub から取得してビルドします。
